1) window.confirm("질문내용");

- confirm 호출 시 "질문내용" 과 "확인/취소" 버튼이 존재하는 알림창이 발생된다.
- 확인 버튼 클릭 시 true / 취소 버튼 클릭 시 false 를 반환한다.



2) window.prompt("질문내용");

- prompt 호출 시 "질문내용" 과 입력할 수 있는 "텍스트상자" 와 "확인/취소" 버튼이 보여지는 알림창이 발생된다.
- 확인버튼 클릭 시 텍스트 상자에 입력되어있는 값 반환
- 취소버튼 클릭 시 null 을 반환
- 아무것도 입력 안하고 확인버튼 클릭 시 빈 문자열 ("") 이 반환
