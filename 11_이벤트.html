이벤트

1. 이벤트란?

- 웹 사이트를 이용하는 사용자에 의해 발생되는 어떤 사건 (클릭, 스크롤 올렸다 내렸다 하기, 키보드키를 치기, 마우스 올리기 등등..)

- 이 이벤트가 발생했을 때, 처리 방법에 대해서 구현하는 것을 "이벤트 처리" 라고 부른다.

* 이벤트 처리 시 고려할 사항
1. event target : 해당 이벤트를 당하는 놈 (요소 객체)
2. event type : 해당 이벤트의 종류
3. event handler : 해당 이벤트가 발생했을 때 실행할 코드 (함수)



2. 이벤트 모델 종류 (이벤트를 처리하는 코드 작성 방법)

  1. 고전 이벤트 모델 (기본 이벤트 모델)
  2. 인라인 이벤트 모델
  3. 표준 이벤트 모델


* 고전 이벤트 모델 (기본 이벤트 모델)

- 요소 객체를 코드상으로 끌고 와서 해당 요소 객체의 이벤트 속성에 직접 접근한 후, 이벤트 핸들러 함수를 대입 (연결) 해주는 방식
- 해당 이벤트 속성에 null 을 대입하는 순간 반대로 이벤트를 제거할 수 도 있다.



* 인라인 이벤트 모델

- 요소의 시작태그쪽에 직접적으로 이벤트 속성을 제시해서 속성값으로 실행할 내용을 코드로 정의하는 방식
- 주로 script 태그 내에 정의되어있는 선언적 함수를 호출하는 방식을 더 선호 (코드의 가독성 때문에)



* 표준 이벤트 모델 (addEventListener 방식)

- 이벤트를 걸고자 하는 요소 객체를 코드상으로 끌고 와서, 해당 요소명으로 부디 addEventListener 라는 메소드를 호출해서 이벤트를 부여해주는 방식
- 표준을 지키지 않는 브라우자 (IE) 에서는 이벤트가 이벤트가 제대로 적용되지 않을 가능성이 큰 방식!! 

        [ 표현법 ]

        요소객체명.addEventListener("이벤트명", function() {});

        - event target : 요소객체명
        - event type : 이벤트명 (click, mouseenter, ... 등 on 이 안붙은것)
        - event handler : function() {}


3. 현재 이벤트가 발생한 해당 요소객체에 접근하는 방법



4. 태그별 기본적으로 가지고 있는 이벤트 제거

- 기본적으로 이벤트를 갖고 있는 요소
1. a 태그 : 클릭 시 href 속성에 제시된 url 을 요청하는 기본이벤트 보유
2. form 태그 내의 submit 버튼 : 클릭 시 사용자가 입력한 값들을 action 에 제시되어있는 url 로 method 에 제시되어있는 방법으로 "요청" 을 하는 기본이벤트 보유
- 태그 내에 기본적으로 설정되어있는 이벤트를 제거하고자 한다면 (즉, 기본이벤트가 실행 안되게끔 막고 싶다면) 이벤트 속성 내부에 return false; 구문이 있어야만 한다!!
