자바스크립트 개요

1. 스크립트 언어란?

- 이미 만들어진 프로그램의 동작을 사용자 (클라이언트) 의 요구에 맞게 수행되도록 해주는 용도
- 즉, 프로그램을 새로이 만들어내는 언어가 아니라 이미 만들어진 프로그램에 추가적인 동작을 덧씌워주는 역할의 언어
- 매우 빠르고 배우고 짧은 소스코드로 기존의 프로그램과 상호작용 하도록 고안된 경우가 많음



2. 자바스크립트란?

- 웹 브라우저에서 가장 많이, 가장 기본적으로 대중적으로 사용되는 "인터프리터 방식" 의 "스크립트 언어"

자바 : 컴파일 방식의 언어 (소스코드가 컴파일 과정을 거치고 나서 실행됨)
자바스크립트 : 인터프리터 방식의 언어 (소스코드가 컴파일 과정 없이 곧바로 한줄씩 읽히고 실행됨)



3. 자바스크립트의 장단점

* 장점

  • 간단한 코드 작성으로 초보자가 접하기 쉬운 언어 (단순한 구조와 원칙)
    예) 접근제한자의 개념 없음, 변수 선언 시 자료횽을 지정할 필요가 없음 (타입추론), 메소드 정의시 반환형 정의 안함
  • 컴파일 과정을 거치지 않기 때문에 수행속도가 빠름
    (코드를 실시간으로 한줄씩 읽어 나가면서 실행됨)


* 단점

  • 웹에 특화된 기술 (내부적으로 제공되는 기능들이 제한적임)
  • HTML 내에 소스코드를 작성하게 되면 개발자 도구를 통해 소스코드가 노출될 수 있음!! (보안상 취약점이 있다)


4. 자바스크립트 소스코드 작성 위치에 따른 종류

  1. inline (인라인) : 이벤트를 부여하고자 하는 요소 내에 간단한 소스코드를 작성해서 실행되게끔 하는 방법
  2. internal (내부) : 해당 이 HTML 문서 내에 script 태그를 쓰고 그 안에 소스코드를 작성해서 실행되게끔 하는 방법
  3. external (외부) : 소스코드들을 별도의 .js 파일로 작성해서 script 태그를 통해 가져다 쓰는 방식

1) inline (인라인) 방식

- 시작태그 내에 직접적으로 실행할 간단한 소스코드를 작성해서 실행시키는 방법
- 주로 실행해야 하는 소스코드가 매우 소량일 경우 사용 

        [ 표현법 ]

        <시작태그 이벤트속성명="해당요소에 해당 이벤트가 발생했을 때 실행할 소스코드;">
            출력할 텍스트 (content 영역)
        </종료태그>


2) internal (내부) 방식

- 이 html 문서 내부에 script 태그 영역 안쪽에 함수단위로 소스코드를 작성해두고, 어떤 html 요소에 어떤 이벤트 발생 시 해당 그 함수를 호출함으로써 실행시키는 방식
- 이 때, script 태그는 head, body 태그 안쪽 아무데서나 작성 가능



3) external (외부) 방식

- 별도의 .js 파일로 소스코드를 작성하고 해당 html 에 가져다가 실행하는 방법
